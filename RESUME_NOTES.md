# ClientFlow Resume Notes

## Suggested project entry

**ClientFlow CRM — PHP, Laravel, React, Inertia, TypeScript, SQLite, Docker**

Built and deployed a full-stack client management application using Laravel and React, featuring authenticated access, client and project CRUD workflows, relational data, server-side validation, dashboard reporting, search/filtering, and responsive UI components.

## Possible resume bullets

- Developed a full-stack client and project management application using PHP, Laravel, React, Inertia, TypeScript, and SQLite.
- Implemented CRUD workflows, relational Eloquent models, server-side validation, client search/filtering, and project status tracking.
- Built dashboard reporting for active clients, pipeline value, open projects, and upcoming delivery dates.
- Containerized the application with Docker for deployment from GitHub to Railway.

## Topics to understand before an interview

- Why Inertia lets Laravel and React work together without a separate REST API
- Laravel routes and controllers
- Eloquent models and the Client → Projects one-to-many relationship
- Request validation and validation errors
- React pages, props, and `useForm`
- Session-based demo authentication
- SQLite migrations and seeding
- How the Dockerfile builds both PHP and React dependencies
